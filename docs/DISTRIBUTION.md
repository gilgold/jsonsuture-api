## Ethical launch copy

**Title:** JSONSuture — repair malformed LLM JSON without another model call

**Short description:** A deterministic HTTP API that fixes malformed or truncated JSON, optionally validates against JSON Schema, and returns structured errors. No inference and no payload retention.

**Hacker News / Show HN:** Explain the narrow failure mode, publish measured latency after sufficient samples, link source and live API, and invite reproducible edge cases. Do not claim customers or benchmarks not observed.

**Reddit / n8n / LocalLLaMA:** Share only in relevant tool-help or project-showcase channels; lead with a working example and disclose that it wraps open-source parsing with hosted auth, quotas, privacy controls, schema validation, and operations.

**API directories:** Submit OpenAPI to Postman Public API Network and relevant API directories after billing activation. An MCP registry submission should wait for an actual remote MCP transport.
